## 매주 할 일
1. 지난 7일간 한국 주요 뉴스 토픽을 웹 검색으로 확인한다.
2. 게임에 넣을 만한 것을 0~3개 고른다.
   - 넣는다: 경제(증시·금리·집값·물가·최저임금), 교육(수능·입시), 기술·생활(AI, 앱, 유행), 스포츠·문화(국가대표, 국제대회), 재난·날씨, 제도 변화.
   - 넣지 않는다: 특정 정치인·정당 평가, 범죄 피해자·가해자, 실명 개인, 확인 안 된 루머.
   - 이미 `src/news_live.js` 에 비슷한 것이 있으면 넣지 않는다.
3. `src/news_live.js` 만 고친다.
   - `NEWS.push(...)` 안에 항목 추가: `{y:올해, a:[최소나이,최대나이], h:'헤드라인', t:'나에게 생긴 일(내 시점, 짧게)', e:{스탯변화}}`
     또는 선택지가 있으면 `c:[{l:'선택', e:{...}, t:'결과'}, ...]` (기존 항목 형식 참고).
   - 스탯 변화는 작게 (±1~6). 조건이 필요하면 `if:S=>...` (예: 직장인만 `!!S.job`).
   - `LIVE_UPDATED` 를 오늘 날짜로 바꾼다.
   - 코스피 종가를 확인해 `KOSPI_LIVE[올해]` 를 (최근 종가 / 전년 말 종가 - 1)×100 으로 갱신한다. 해가 바뀌면 전년 값을 확정하고 새해 키를 추가한다.
   - 기존 항목의 순서나 내용은 바꾸지 않는다 (저장된 게임의 뉴스 번호가 어긋난다).
4. 검증 (`life-game/src` 에서):
   - `python3 assemble3.py`
   - `node simrt.js 300` → `errors 0`
   - `node pw4.js "$PWD/../오천만분의일.html" /tmp` → `"errs":[]`, `"ended":true`
5. `life-game/오천만분의일.html` 을 Artifact 로 위 주소에 다시 배포한다 (먼저 read 후 같은 url 로 publish).
6. 커밋 후 `claude/game-analysis-comparison-3f8iqx` 브랜치에 push.
7. 바뀐 내용을 2~3줄로 요약해 보고한다. 넣을 만한 뉴스가 없으면 날짜만 갱신하고 그렇게 보고한다.
