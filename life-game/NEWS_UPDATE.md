## 매주 할 일
1. Artifact `read` 로 위 주소의 페이지를 읽는다 (저장된 로컬 파일 경로가 결과에 나온다).
   `dev/pw4.js` 도 `read` (path) 로 받아둔다.
2. 지난 7일간 한국 주요 뉴스 토픽을 웹 검색으로 확인하고, 게임에 넣을 만한 것을 0~3개 고른다.
   - 넣는다: 경제(증시·금리·집값·물가·최저임금), 교육(수능·입시), 기술·생활(AI, 앱, 유행), 스포츠·문화, 재난·날씨, 제도 변화.
   - 넣지 않는다: 특정 정치인·정당 평가, 범죄 피해자·가해자, 실명 개인, 확인 안 된 루머, 이미 들어간 것과 비슷한 것.
3. 페이지 안의 `/* ===== 실시간 뉴스: 매주 자동 업데이트되는 파일 =====` 블록만 고친다.
   - `NEWS.push(` 안 맨 끝에 항목 추가 (기존 항목 순서·내용은 절대 바꾸지 않는다: 저장된 게임의 뉴스 번호가 어긋난다).
     형식: `{y:올해, a:[최소나이,최대나이], h:'헤드라인', t:'나에게 생긴 일(내 시점, 1~2문장)', e:{행:2}}`
     선택지형: `c:[{l:'선택', e:{...}, t:'결과'}, {l:'다른 선택', e:{}, t:'결과'}]`
     스탯 키: 학 체 멘 행 인 매 돈(만원) · 변화는 ±1~6. 조건: `if:S=>!!S.job` (직장인), `if:S=>!S.job` 등.
   - `LIVE_UPDATED` 를 오늘 날짜로.
   - `KOSPI_LIVE[올해]` = (최근 코스피 종가 / 전년 말 종가 - 1) × 100. 2025년 말 종가는 약 4,214.
     해가 바뀌면 전년 값을 연말 종가로 확정하고 새해 키를 추가한다.
4. 검증: 고친 HTML 을 `node pw4.js <html 절대경로> <출력폴더>` 로 실행 → `"errs":[]` 와 `"ended":true` 확인.
   (playwright 는 설치되어 있다. 실패하면 배포하지 말고 원인을 보고한다.)
5. 같은 url 로 Artifact publish (edits 로 블록만 바꾸는 것이 가장 안전하다).
6. 무엇을 넣었는지 2~3줄로 보고한다. 넣을 뉴스가 없으면 날짜·코스피만 갱신하고 그렇게 보고한다.
